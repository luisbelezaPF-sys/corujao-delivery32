# 🦉 Corujão Lanches & Açaí - Delivery Premium

Sistema completo de delivery para lanches artesanais e açaí com pedidos via WhatsApp.

## 🚀 Funcionalidades

- **Cardápio Digital**: Lanches artesanais e açaí personalizado
- **Carrinho de Compras**: Sistema completo de pedidos
- **Integração WhatsApp**: Envio automático de pedidos
- **Painel Administrativo**: Gestão de pedidos e cupons fiscais
- **Design Responsivo**: Funciona perfeitamente em mobile e desktop

## 🛠️ Tecnologias

- Next.js 15 com App Router
- React 19 e TypeScript
- Tailwind CSS v4
- Lucide Icons
- Shadcn/ui Components

## 📱 Como Usar

1. Acesse o site
2. Navegue pelo cardápio
3. Monte seu açaí personalizado
4. Adicione itens ao carrinho
5. Finalize o pedido via WhatsApp

## 🔧 Instalação

```bash
# Instalar dependências
npm install

# Executar em desenvolvimento
npm run dev

# Build para produção
npm run build
```
